# Blue Screen Of Death

A collection of authentic Blue Screen of Death (BSOD) web replications built with pure HTML, CSS, and minimal JavaScript.

---

## Featured Replications
### 1. Modern Windows BSOD
Recreation of the modern Windows 10/11 error screen featuring the sad emoticon `:(` and QR code layout.
* **Reference:** [Dell Support BSOD Image](https://i.dell.com/sites/csimages/App-Merchandizing_esupport_flatcontent_global_Images/all/bluescreen.png)

---

### 2. Windows 9x BSOD
The iconic classic blue screen from Windows 95, 98, and Millennium Edition.
* **Font:** Monospace / Fixedsys
* **Reference:** [Wikimedia - Windows 9X BSOD](https://upload.wikimedia.org/wikipedia/commons/3/3b/Windows_9X_BSOD.png?utm_source=en.wikipedia.org&utm_campaign=index&utm_content=original)

---

### 3. Windows NT 4.0 / 3.x BSOD
The detailed kernel debug memory dump screen used in Windows NT 3.51 & NT 4.0.
* **Reference:** [Wikimedia - Windows NT BSOD](https://upload.wikimedia.org/wikipedia/commons/6/61/Windows_NT_3.51_BSOD_ita.png?utm_source=en.wikipedia.org&utm_campaign=index&utm_content=original)

---

### 4. Windows 1.0 "Mojibake" BSOD
The scrambled character text screen resulting from a fatal crash in Windows 1.0.
* **Reference:** [Wikimedia - Windows 1.0 BSOD](https://upload.wikimedia.org/wikipedia/commons/c/c1/BSoD_in_Windows_1.0.png?utm_source=en.wikipedia.org&utm_campaign=index&utm_content=original)
